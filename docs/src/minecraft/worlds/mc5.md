**Minecraft** 26.3

The world that used to run on a home PC over Tailscale, at
`100.119.218.72:41641`, moved here on 2026-11-20 with its world folder. It
ran 1.21.10; it now runs 26.3, the newest release every one of its mods
supports. The mod list is the old server's, each mod at its 26.3 build:
almost all of it is server-side performance (Lithium, C2ME, Async, VMP,
ServerCore, TT20), so the game itself plays as vanilla. Distant Horizons is
the one mod worth installing on your side, and the pack has it.

The old server shipped NeoForge jars of ServerCore and FerriteCore beside
the Fabric ones, and a Forge build of Entity Culling. Fabric never loads
those, so the pack carries only the Fabric builds.
